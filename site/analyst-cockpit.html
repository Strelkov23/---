ЭКСПЕРИМЕНТ / ЛОКАЛЬНАЯ МОДЕЛЬ

Экономический ИИ — исследовательский прототип

Объяснение ограниченного набора независимых наблюдений: hh.ru, торговая статистика США, РОМИР. Не прогноз и не автоматическое принятие решений. Ответ может содержать ошибки.

Модель Qwen2.5 1.5B выполняется в браузере через WebGPU. При первой загрузке нужны доступ к CDN и Hugging Face и достаточная память GPU (ориентир 1,6 ГБ VRAM). Запрос не отправляется в API языковой модели. Без модели можно проверить исходные данные.

Дата наблюдения не равна дате публикации; это не ретроспективный срез доступной на тот момент информации.
